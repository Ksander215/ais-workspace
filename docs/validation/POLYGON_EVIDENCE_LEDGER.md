# AIS Polygon Evidence Ledger

This is the working ledger for Polygon findings.

## Run record

For every run record:

- Repository:
- Repository commit SHA:
- AIS commit SHA:
- Date/time:
- Environment:
- Question:
- AIS output:
- Claims sampled:
- Evidence returned by AIS:
- Independent verification:
- Finding:
- Classification:
- Severity:
- Reproducible:
- Decision:
- Notes:

## Finding classification

- BLOCKER
- QUALITY GAP
- EVIDENCE GAP
- CONTEXT/CONTINUITY GAP
- UX/COMPREHENSION GAP
- RUNTIME GAP
- ARCHITECTURE GAP
- NOT A GAP / EXPECTED LIMITATION

## Severity

- P0 — prevents or invalidates the validation path
- P1 — materially affects trust or core value
- P2 — meaningful friction or quality issue
- P3 — cosmetic/non-critical

## Decision

- BUILD — justified change required
- DEFER — valid but not on the critical path
- REJECT — not a meaningful AIS gap

## Important

Do not record a failure as an architecture gap until runtime, evidence, context and UX explanations have been considered.
